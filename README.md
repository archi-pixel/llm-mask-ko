# llm-mask-ko

한국어 민원·문의 글을 LLM에 보내기 **직전에** 개인정보를 지우는 함수입니다.
외부 라이브러리를 쓰지 않는 파일 하나(llm-mask.js, 263줄)와 검사 52개가 전부입니다.

```js
const { maskForLlm } = require('./llm-mask');

maskForLlm('제2공학관 27501호 에어컨 고장입니다. 연락처 010-1234-5678, 김철수 교수님 연구실.');
// {
//   text: '제2공학관 27501호 에어컨 고장입니다. 연락처 [전화], [이름] 교수님 연구실.',
//   hits: { phone: 1, rrn: 0, email: 0, studentId: 0, name: 1 }
// }
```

호실번호(`27501호`)가 **그대로 남는 것**이 이 함수의 핵심입니다.

---

## 왜 만들었나

성균관대학교 자산관리처에서 시설민원을 분류하는 데 씁니다.
민원 글은 미국에 있는 회사 서버로 나가는데, 민원 본문은 자유롭게 쓰는 칸이라
이름과 전화번호가 섞여 들어옵니다. 그래서 나가기 직전에 지웁니다.

그런데 **다 지우면 안 됩니다.** 호실번호와 증상 서술이 사라지면 AI가 판단할 재료가 없어지고,
틀린 분류는 곧바로 민원인에게 불편으로 돌아갑니다.

그래서 원칙을 이렇게 잡았습니다. **확실할 때만 지운다.**
확실할 때만 지운다는 것은 **못 지우고 나가는 것이 있다**는 뜻이기도 합니다.
무엇이 안 지워지는지는 아래 「못 잡는 것」에 있습니다.

## 무엇을 지우고 무엇을 남기나

### 지웁니다

| 항목 | 바뀌는 말 | 예 |
|---|---|---|
| 이메일 | `[메일]` | `test.user@example.com` |
| 주민등록번호 | `[주민번호]` | `900101-1234567`, 하이픈 없는 13자리, `900101 1234567`처럼 띄어 쓴 것 |
| 학번 | `[학번]` | `2019123456` (20으로 시작하는 10자리) |
| 전화번호 | `[전화]` | `010-1234-5678`, `010 - 1234 - 5678`, `02)760-1234`, `0507-1234-5678`, `+82 10-1234-5678` |
| 호칭이 붙은 이름 | `[이름]` | `김철수 교수님`, `홍길동님께`, `이영희 학생입니다`, `김철수 교수님하고` |

바뀌는 말을 항목마다 다르게 뒀습니다. 전부 `[개인정보]`로 뭉개면
「연락처를 남겼다」는 문맥까지 사라져서 LLM이 긴급도를 잘못 볼 수 있습니다.

표기가 조금 달라도 같이 봅니다.
하이픈 대신 쓴 `–`·`—`·`ㅡ`, 폭이 넓은 전각 숫자(`０１０`), 숫자 사이에 숨은 보이지 않는 공백 문자,
맥에서 복사해 글자가 자음·모음으로 쪼개진 한글도 잡습니다.

### 남깁니다

호실번호 · 건물명 · 동 · 층 · 증상 서술 · 날짜 · 시간 · 금액 · 접수번호.
전부 분류에 필요한 정보이고, 사람을 가리키지 않습니다.

지운 자리 말고는 글자를 바꾸지 않습니다. 전각 숫자로 쓴 `２층`도 그대로 나갑니다.
(맥에서 복사해 쪼개진 한글만 보통 한글로 모아서 내보냅니다. 보이는 글자는 같습니다.)

## 지우는 순서

**이메일은 반드시 맨 먼저 지웁니다.**
학번·전화 규칙이 먼저 돌면 메일 주소 앞쪽 숫자만 지워지고 뒷부분(도메인)이 남습니다.
`2026012345@example.ac.kr`이 `[학번]@example.ac.kr`로 나가는 식입니다.

나머지는 순서를 바꿔도 결과가 같습니다(순서 120가지를 문장 5천여 개에 돌려 확인했습니다).

1. **이메일**
2. **주민등록번호** — 13자리.
3. **학번** — 20으로 시작하는 10자리.
   날짜(`20260826`, 8자리)와 접수번호(`FR-20260826-001`)는 자릿수가 달라 안 걸립니다.
4. **전화번호** — 0으로 시작하는 9~12자리.
5. **이름** — 마지막. 앞에서 바뀐 `[전화]` 같은 말은 이름 규칙에 걸리지 않습니다.

2~4번이 서로 엉키지 않는 것은 **앞뒤 숫자 경계** 덕분입니다.
번호 바로 앞이나 뒤에 숫자가 또 붙어 있으면 그 번호로 보지 않는다는 조건입니다.
이 조건이 없으면 긴 숫자 안쪽이 번호로 잘려 나갑니다.
`3000000000원`은 `3[전화]원`이 되고, 12자리 주문번호 `202012345678`은 `[학번]78`이 됩니다.

## 이름은 조건 세 개를 다 만족해야 지웁니다

1. 흔한 성씨로 시작 (한 글자 39자 + 남궁·황보·제갈·사공·선우·독고)
2. 전체 두~네 글자
3. **호칭이 반드시 붙음**

호칭과 그 뒤에 붙는 말은 이름 길이에 따라 다르게 받습니다.

- **세 글자 이상 이름**(`김철수`, `남궁민수`)은 넓게 받습니다.
  - 호칭: 교수·선생·박사·조교·연구원·주임·대리·과장·팀장·부장·처장·학생(님이 있든 없든),
    조교수·부교수·명예교수 같은 교수 직함, 책임연구원·선임연구원,
    그리고 강사·책임·선임·수석·실장·소장·원장·차장·주무관·행정관·센터장·본부장·학장·서무(뒤에 **님**이 붙을 때만), 님, 씨
  - 뒤에 붙는 말: 이·가·께·께서·에게·입니다 같은 조사와 어미, 그리고 하고·으로부터·까지·부터·처럼·네·교수실의 「실」 등
- **두 글자 이름**(`김혁`)은 처음 규칙 그대로만 받습니다.
  `우리`·`이상`·`조금` 같은 흔한 낱말과 겉모양이 같아서입니다.

이름 자리 **마지막 글자**도 봅니다.

- `에`·`과`·`처`·`팀`·`당`·`반`·`층`·`앞`·`쪽` 등 사람 이름 끝에 쓰지 않는 글자로 끝나면 이름으로 보지 않습니다
  (`최근에 교수님께서`, `전산과 선생님`, `정문앞 학생`).
- `실`·`장`·`관`·`소`·`청`·`회`·`한` 등 장소·단체 이름 끝에 흔한 글자로 끝나거나, 막아 둔 낱말로 시작하면
  넓힌 호칭·조사로는 잡지 않고 처음 규칙으로만 봅니다(`전기실 과장님하고`, `오늘은 과장님하고`는 그대로).
  이 글자로 끝나는 실제 이름(`김은실`, `박영관`)도 있어서, 처음 규칙으로 잡히던 `김은실 선생님이`는 지금도 잡힙니다.
- 직함 뒤에 `실`이 붙은 방 이름(`조교실`)도 이름으로 보지 않습니다.

호칭과 함께 한 번 잡힌 세 글자 이상 이름은 같은 글에서 호칭 없이 다시 나와도 지웁니다.
`김철수 교수님 … 김철수에게` → `[이름] 교수님 … [이름]에게`. 다른 낱말 안쪽(`홍길동전`)은 건드리지 않습니다.

성씨로 시작하지만 사람 이름이 아닌 낱말은 목록으로 막아 뒀습니다
(`고객`, `강의실`, `전기`, `우리`, `신임`, `전임`, `남자`, `이모`, `강사`, `서무`, `신고자`, `이미`, `오신`, `주신` …).
이름이 직함이나 부서로 끝나도 사람 이름으로 보지 않습니다 (`정교수`, `주임`, `주무관`, `전기팀`).

운영 중에 오탐이 보고되면 정규식을 고치지 말고 **`NAME_STOPWORDS`에 낱말을 추가**하세요.
그쪽이 훨씬 안전합니다.

## 못 잡는 것

한계를 그대로 적습니다. 아래는 전부 직접 넣어 보시면 확인됩니다.

**호칭이 없으면 이름을 못 거릅니다.**
`담당자 정하늘 확인요망`, `신고자 김철수`, `성명: 김철수`가 그렇고,
`교수 김철수 연구실`처럼 호칭이 앞에 오는 것도 못 거릅니다.
성 없이 이름만 쓴 `철수 씨`, `민수 학생이`도 그대로 나갑니다.

**성씨 목록 밖의 성은 호칭이 붙어도 지나갑니다.**
나·민·진·지·엄·채·원·천·방·공·현·함·변·염·여·추·도·소·석·선·설·마·길·연·위·표 같은 성입니다.
`민경훈 님`, `진선미 교수님`, `천지훈 교수님`은 그대로 나갑니다.
목록을 늘려 보니 `지도 교수님`·`현재 교수님`·`여러 학생이` 같은 말이 이름으로 지워져서(시험한 49문장 중 45문장) 늘리지 않았습니다.

**넓힌 규칙을 쓰지 않는 이름이 있습니다.**
두 글자 이름(`김혁 강사님`, `김혁 교수님하고`)이 그렇고, 다시 나온 `김혁에게`도 안 지웁니다.
끝 글자가 실·장·관·소·한 등인 이름(`김은실 선생님하고`)과 막아 둔 낱말로 시작하는 이름(`이미진 교수님하고`)도
「하고」「까지」 뒤나 새로 넣은 직함에서는 못 잡습니다. 처음 규칙(`교수님이`, `선생님께`)으로는 잡습니다.
성 한 글자에 이름이 세 글자인 `김수한무 교수님`도 못 잡습니다.

**목록에 없는 호칭과 형태는 지나갑니다.**
`기사님`·`이사님`·`대표님`·`총장님`·`반장님`·`주사님`·`여사님`·`선배`·`군`·`양`이 그렇고,
`김철수 학생들`·`홍길동님들`처럼 여럿을 가리키는 말, `교수님측`도 못 잡습니다.

**표기가 많이 다르면 지나갑니다.**
- 이름: 붙여 쓴 `담당자김철수 교수님`, 쉼표·괄호로 끊은 `김철수, 교수님`·`김철수(교수)`, 영문 이름 `John Smith`
- 전화: 쉼표·슬래시·물결·밑줄·줄바꿈으로 끊은 번호(`010/1234/5678`), 한글로 쓴 숫자(`공일공`)
- 메일: `test @ example.com`처럼 @ 앞뒤를 띄운 것, `test [at] example.com`, 한글이 섞인 주소
- 주민번호: 뒷자리 첫 숫자가 9·0인 것(1800년대생), `/`로 끊은 것
- 학번: `2019-312345`처럼 끊어 쓴 것

**다섯 가지 밖은 처음부터 지우지 않습니다.**
주소, 계좌번호, 차량번호, 카드번호, 생년월일만 쓴 것(`1990.08.16`), 여권·운전면허 번호, 메신저 아이디는 그대로 나갑니다.

**반대쪽도 뚫립니다.**
- 숫자: 쉼표 없는 10자리 금액 `2050000000원`은 학번으로 보여 `[학번]원`이 되고,
  `2026082614`처럼 20으로 시작하는 10자리 일련번호도 `[학번]`이 됩니다.
  0으로 시작하는 9~12자리 계량기·자산 번호(`012345678`)는 `[전화]`가 됩니다.
  날짜처럼 보이는 6자리 뒤에 띄우고 7자리가 오면(`241027 1234567`) 주민번호로 봅니다.
- 이름: 성씨 글자로 시작하는 낱말 뒤에 호칭이 오면 이름으로 봅니다.
  자주 나오는 것은 막아 뒀지만 목록에 없는 낱말은 지워집니다.
  `조금 교수님께` → `[이름] 교수님께`, `성실한 학생이` → `[이름] 학생이`, `전기실 과장님이` → `[이름] 과장님이`.
  이런 낱말은 `NAME_STOPWORDS`에 넣어 막습니다.

그래도 멀쩡한 말을 지우는 쪽이 더 위험하다고 봤습니다.
`전기 과장 부재중이었습니다`, `고객님 응대 관련 문의` 같은 문장에서 이름이 아닌 말을 지우면
민원 내용이 무너집니다.

**그러니 이 함수 하나만 믿지 마세요.** 국외로 나간다는 사실과 보관 기간을 개인정보처리방침에 같이 적어 두세요.

```js

const masked = maskForLlm(민원원문);

await callOpenAI({ text: masked.text, ... });
```

오탐이 나는 낱말은 이렇게 더합니다.

```js
NAME_STOPWORDS.add('조금');
```

**중요한 건 함수가 아니라 위치입니다.**
그 기능에서 LLM을 부르는 경로를 코드에 한 곳만 두고, 그 길목에 조건 없이 넣으세요.
켜고 끄는 설정값을 만들면 언젠가 꺼진 채로 나갑니다.

반환값에는 원문이 어디에도 담기지 않습니다. 바뀐 글과 **지운 개수**뿐입니다.

100만 자를 넣어도 1초 안에 끝납니다. 그래도 LLM에 보낼 글은 길이 상한을 두는 편이 좋습니다.
자를 때는 지운 다음에 자르세요. 먼저 자르면 경계에 걸린 번호가 반쪽만 남을 수 있습니다.
