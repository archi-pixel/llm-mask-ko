# llm-mask-ko

한국어 민원·문의 글을 LLM에 보내기 **직전에** 개인정보를 지우는 함수입니다.
외부 라이브러리를 쓰지 않는 순수 함수 하나(138줄)와 검사 30개가 전부입니다.

```js
const { maskForLlm } = require('./llm-mask');

maskForLlm('제2공학관 27501호 에어컨 고장입니다. 연락처 010-1234-5678, 김철수 교수님 연구실.');
// {
//   text: '제2공학관 27501호 에어컨 고장입니다. 연락처 [전화], [이름] 교수님 연구실.',
//   hits: { phone: 1, rrn: 0, email: 0, studentId: 0, name: 1 }
// }
```

호실번호(`27501호`)가 **그대로 남는 것**이 이 함수의 핵심입니다.

---

## 왜 만들었나

성균관대학교 자산관리처에서 시설민원을 분류하는 데 씁니다.
민원 글은 미국에 있는 회사 서버로 나가는데, 민원 본문은 자유롭게 쓰는 칸이라
이름과 전화번호가 섞여 들어옵니다. 그래서 나가기 직전에 지웁니다.

그런데 **다 지우면 안 됩니다.** 호실번호와 증상 서술이 사라지면 AI가 판단할 재료가 없어지고,
틀린 분류는 곧바로 민원인에게 불편으로 돌아갑니다.

그래서 원칙을 이렇게 잡았습니다. **확실할 때만 지운다.**
확실할 때만 지운다는 것은 **못 지우고 나가는 것이 있다**는 뜻이기도 합니다.
무엇이 안 지워지는지는 아래 「못 잡는 것」에 있습니다.

---

## 무엇을 지우고 무엇을 남기나

### 지웁니다

| 항목 | 바뀌는 말 | 예 |
|---|---|---|
| 이메일 | `[메일]` | `test.user@example.com` |
| 주민등록번호 | `[주민번호]` | `900101-1234567`, 하이픈 없는 13자리도 |
| 학번 | `[학번]` | `2019123456` (20으로 시작하는 10자리) |
| 전화번호 | `[전화]` | `010-1234-5678`, `02)760-1234`, `0507-1234-5678`, `070-8888-9999` |
| 호칭이 붙은 이름 | `[이름]` | `김철수 교수님`, `홍길동님께`, `이영희 학생입니다` |

바뀌는 말을 항목마다 다르게 뒀습니다. 전부 `[개인정보]`로 뭉개면
「연락처를 남겼다」는 문맥까지 사라져서 LLM이 긴급도를 잘못 볼 수 있습니다.

### 남깁니다

호실번호 · 건물명 · 동 · 층 · 증상 서술 · 날짜 · 시간 · 금액 · 접수번호.
전부 분류에 필요한 정보이고, 사람을 가리키지 않습니다.

---

## 지우는 순서가 정해져 있습니다

바꾸면 오탐이 납니다.

1. **이메일** — 통째로 지워야 도메인이 안 남습니다.
   `2026012345@example.ac.kr`을 학번 규칙이 먼저 건드리면 `example.ac.kr`이 남습니다.
2. **주민등록번호** — 13자리. **전화보다 먼저.**
   지금은 4번의 앞뒤 숫자 경계 덕분에 전화 규칙이 13자리 안으로 들어오지 못하지만,
   경계를 빼면 앞 9~12자리가 전화번호로 잘려 나가고 뒷자리가 남습니다.
3. **학번** — 20으로 시작하는 10자리.
   날짜(`20260826`, 8자리)와 접수번호(`FR-20260826-001`)는 자릿수가 달라 안 걸립니다.
4. **전화번호** — 0으로 시작하는 9~12자리. **앞뒤 숫자 경계가 핵심 방어**입니다.
   이게 없으면 `27501호`, `1500000원`, `20260826` 안쪽의 0에서 매치가 시작됩니다.
5. **이름** — 마지막. 앞에서 바뀐 `[전화]` 같은 말은 성씨 목록에 안 걸립니다.

---

## 이름은 조건 세 개를 다 만족해야 지웁니다

1. 흔한 성씨로 시작 (한 글자 39자 + 남궁·황보·제갈·사공·선우·독고)
2. 전체 두~네 글자
3. **호칭이 반드시 붙음** — 교수·선생·박사·조교·연구원·주임·대리·과장·팀장·부장·처장·학생, 또는 님·씨

여기에 더해, 성씨로 시작하지만 사람 이름이 아닌 낱말은 목록으로 막아 뒀습니다
(`고객`, `강의실`, `안전`, `전기`, `정보`, `주차`, `오늘`, `문의`, `배관`, `조명` …).
이름이 직함으로 끝나도 사람 이름으로 보지 않습니다 (`정교수`, `주임`, `박사`).

운영 중에 오탐이 보고되면 정규식을 고치지 말고 **`NAME_STOPWORDS`에 낱말을 추가**하세요.
그쪽이 훨씬 안전합니다.

## 못 잡는 것

한계를 그대로 적습니다. 아래는 전부 직접 넣어 보시면 확인됩니다.

**호칭이 없으면 이름을 못 거릅니다.**
`담당자 정하늘 확인요망`이 그렇고, `교수 김철수 연구실`처럼 호칭이 앞에 오는 것도 못 거릅니다.
사람 이름인지 아닌지 가릴 근거가 없어서 일부러 보수적으로 뒀습니다.

**성씨 목록 39자 밖의 성은 호칭이 붙어도 지나갑니다.**
천·표·엄·마 같은 성이라 `천지훈 교수님`은 그대로 나갑니다.
직함도 `TITLE`에 있는 12개(교수·선생·박사·조교·연구원·주임·대리·과장·팀장·부장·처장·학생)뿐이어서
`김철수 차장님`은 안 지워집니다. 실장·소장·원장·기사도 마찬가지입니다.

**표기가 조금만 달라도 지나갑니다.**
`담당자김철수 교수님`처럼 붙여 쓰면 못 잡고, 영문 이름(`John Smith`)과
`+82`로 시작하는 국제전화 표기도 못 잡습니다.

**반대쪽도 뚫립니다.**
`정하늘 주무관님`은 「주무관」이 성씨 규칙에 걸려 `정하늘 [이름]님`이 되고,
쉼표 없는 10자리 금액 `2050000000원`은 학번으로 보여 `[학번]원`이 됩니다.
`오전반 학생`도 `[이름] 학생`이 됩니다. 이런 오탐은 `NAME_STOPWORDS`에 낱말을 넣어 막습니다.

그래도 멀쩡한 말을 지우는 쪽이 더 위험하다고 봤습니다.
`전기 과장 부재중이었습니다`, `고객님 응대 관련 문의` 같은 문장에서 이름이 아닌 말을 지우면
민원 내용이 무너집니다.

**그러니 이 함수 하나만 믿지 마세요.** 국외로 나간다는 사실과 보관 기간을 개인정보처리방침에 같이 적어 두세요.

## 검사 30개 — 절반 가까이가 「지우면 안 되는 것」 검사

```bash
node --test
```

| 무엇을 보는가 | 개수 |
|---|---|
| 지워야 할 것이 지워졌는가 | 12 |
| **지우면 안 되는 것을 안 지웠는가** | **14** |
| 실제 민원처럼 생긴 문장에서 연락처만 지워지는가 | 2 |
| 빈 입력·돌려주는 값 방어 | 2 |

14개 가운데 12개는 제목에 「위양성」이 붙어 있고, 나머지 2개는 이름 오탐 방지 검사입니다.

「지우면 안 되는 것」 검사가 실제로 보는 문장들:

```
3동 5층 복도 천장에서 물이 떨어집니다      ← 동·층
2026-08-26 부터 증상이 있습니다            ← 날짜
접수번호 FR-20260826-001 조회했습니다      ← 접수번호
14:30 경, 09:05 에도 동일 증상             ← 시간
고객님 응대 관련 문의드립니다              ← 호칭처럼 보이는 일반명사
엘리베이터 기사님이 다녀갔습니다
학생회관 2층 화장실 누수                   ← 학생 + 회관
시설팀 주임님께 전달했습니다               ← 이름 없이 직함만
온도가 0도까지 떨어집니다                  ← 숫자 오탐
계량기 번호 0123456
```

검사 파일 첫머리에 이렇게 적어 뒀습니다.

> ★ 테스트 데이터는 전부 가짜다. 실재 번호·실재 인물 이름을 넣지 말 것
> (테스트 파일도 저장소에 남고, 저장소는 개인정보 보관 장소가 아니다).

운영 저장소에는 검사가 32개인데, 그중 2개는 실제 전송 경로가 마스킹본만 내보내는지
확인하는 통합 검사라 운영 저장소의 다른 모듈이 있어야 돌아갑니다. 여기서는 뺐습니다.

## 쓰는 법

파일 하나를 복사해 가세요. 설치할 것도, 의존성도 없습니다.

```js
const { maskForLlm, totalHits, NAME_STOPWORDS } = require('./llm-mask');

const masked = maskForLlm(민원원문);
const 지운개수 = totalHits(masked.hits);

// 이 아래로는 masked.text 만 나갑니다
await callOpenAI({ text: masked.text, ... });
```

**중요한 건 함수가 아니라 위치입니다.**
그 기능에서 LLM을 부르는 경로를 코드에 한 곳만 두고, 그 길목에 조건 없이 넣으세요.
켜고 끄는 설정값을 만들면 언젠가 꺼진 채로 나갑니다.

반환값에는 원문이 어디에도 담기지 않습니다. 바뀐 글과 **지운 개수**뿐입니다.
